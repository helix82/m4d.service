# M4D Microservice

Микросервис для работы с машинно-читаемыми доверенностями (МЧД).

**Архитектура**

Микросервис построен на основе Spring Boot и работает по принципу REST API.

**Основные компоненты**

- Контроллеры: обеспечивают обработку входящих HTTP-запросов.
- Сервисы: реализуют бизнес-логику взаимодействия с РПД.
- Репозитории: взаимодействие с БД.
- Клиенты API: для отправки запросов в систему РПД.

**Основные возможности**

- Ведение реестра МЧД (создание, редактирование и удаление МЧД, загрузка и хранение электронной подписи).
- Проверка МЧД через распределенный реестр (РР) МЧД ФНС.
- Ведение справочника полномочий (создание, редактирование и удаление)
- Ведение журнала заявлений на отзыв МЧД (создание, редактирование и удаление заяления, загрузка и хранение электронной подписи)
- Регистрация, отзыв и проверка МЧД в РР МЧД ФНС через ПВВ и ПВВ РР МЧД адаптер.

# Локальная настройка M4D

1. Прописать в hosts 10.1.176.210 sso.rpd.zk.test.st 
2. Установить OpenVPN
3. Взять конфиг у девопса и в директорию конфиг его добавить (конфиг у девопса брать)
4. Включить впн и можно работать 

# Продакшн-настройка M4D

Для корректной работы микросервиса МЧД в продакшн-окружении требуется выполнить следующие шаги настройки.

1. **Подключение к системе РПД**

Для полноценного функционирования микросервиса необходимо обеспечить доступ к системе РПД.

Требования:

- Доступ к API системы РПД:

Убедитесь, что сеть микросервиса позволяет подключаться к API РПД. Если API защищено, убедитесь, что предоставлены необходимые данные для аутентификации (токены, ключи и т. д.).

- Настройка окружения:

Убедитесь, что в values хелмов указаны корректные данные

2. **Настройка базы данных (PostgreSQL 14)**

Микросервис использует PostgreSQL для хранения данных.

Требования к базе данных:
- Версия: PostgreSQL 16.
- Создание базы данных:

Создайте базу данных для микросервиса с именем m4d_db.

**Предварительные требования**

- Java 11 Bellsoft Liberica Full
- Maven
- Postgres 16
- Доступ к системе РПД

P.S. Необходимо в values хелмов в значение tag добавить необходимый тэг образа.
